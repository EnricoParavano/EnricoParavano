- Chiedimi di automazione AI per le PMI, integrazioni n8n/Zapier, edge AI e computer vision
- Curiosità: nella mia tesi ho portato il riconoscimento di oggetti in tempo reale (YOLOv8) su un Raspberry Pi per applicazioni con droni
